## Regras

1. Todo download novo: adicionar linha na tabela acima ANTES de usar no jogo.
2. Espelhos GitHub do 0x72: são reuploads de terceiros. Baixar o pacote oficial do itch.io para conferência antes do release (licença original CC0 confirmada na página).
3. CC-BY (linha 27): só usar com crédito visível; preferir CC0.
4. `selection.json` (gerado pelo asset browser) = decisões de uso por arquivo/frame. Só o que estiver marcado como `use` entra no jogo.
